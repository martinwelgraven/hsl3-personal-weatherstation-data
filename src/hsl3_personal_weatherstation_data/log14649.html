1. Description

Parses weather data received from a personal weather station. Measurements include temperature, humidity, pressure, rainfall, and vapor pressure deficit. Unit output is based on the corresponding input fields. Currently Ecowitt protocol is supported. Others may be added in the future.
Note

2. Inputs

No. Name Initialisation Description
1 Data (x-www-form-urlencoded)
Weather data received from the Ecowitt station as URL-encoded form data.
2 Temperature (1-Celcius, 0-Fahrenheit) 1
Select the temperature unit used by the station: 1 for Celsius or 0 for Fahrenheit.
3 Windspeed (1-km/h, 0-mph) 1
Select the wind speed unit used by the station: 1 for km/h or 0 for mph.
4 Pressure (1-bar, 0-hPa) 1
Select the pressure unit used by the station: 1 for bar or 0 for hPa.
5 Rainfall (1-mm, 0-inch) 1
Select the rainfall unit used by the station: 1 for millimetres or 0 for inches.
6 Vapor Pressure Deficit (2-mbar, 1-hPa, 0-kPa) 1
Select the VPD unit used by the station: 2 for mbar, 1 for hPa, or 0 for kPa.
