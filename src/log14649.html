1. Description

A simple logic node to process an JSON message based on the Ecowitt protocol. Version 1.0 contains solely the version for a weatherstation based on the protocol used by the Alecto WS5500.

2. Inputs

No. Name Initialisation Description
1 E1 - Ecowitt JSON ""
A valid JSON string with an Ecowitt message
2 E2 - Temperature to Celcius 0
Either 0 (default) for output in Fahrenheit or a 1 for output in Celcius
2 E3 - Speed to km per hour 0
Either 0 (default) for output in miles per hour or a 1 for output in kilometer per hour
2 E4 - Pressure to Bar 0
Either 0 (default) for output in hectopascal or a 1 for output in bar
2 E5 - Length to mm 0
Either 0 (default) for output in inch or a 1 for output in mm
2 E5 - kPa to hPa or mbar 0
Either 0 (default) for output in kPa, 1 for hPa or 2 of mbar
